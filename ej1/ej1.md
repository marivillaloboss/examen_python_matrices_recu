## Consigna:

Crear un manipulador básico de matrices.

Esto es un programa que muestre un menú y permita:

1. Cargar una matriz (15p)
    - Se pedirá la cantidad de filas y la cantidad de columnas
    - Se pedirá elemento a elemento para llenar la matriz
    - Si ya había una matriz cargada previamente, la sobreescribe
2. Mostrar la matriz cargada (15p)
    - Debe mostrar la matriz iterando fila a fila, NO imprimiendo la matriz así nomás.
3. Sumatoria (15p)
    - Esta opción debe imprimir la suma de todos los elementos de la matriz.
4. Productoria (15p)
    - Esta opción debe imprimir el producto de todos los elementos de la matriz.
5. Transpuesta (20p)
    - Esta opción debe imprimir la matriz transpuesta, esto es: Debe imprimir la misma matriz, pero cambiando las filas por columnas. Ejemplo:

    Matriz inicial:                 Matriz transpuesta:

    [1, 2, 3]                       [1, 4, 7]
    [4, 5, 6]                       [2, 5, 8]
    [7, 8, 9]                       [3, 6, 9]

    El resultado es una matriz cuya primera fila [1, 4, 5] es la primer columna de la matriz original [1]
                                                                                                      [4]
                                                                                                      [7]
                                                                                                
6. El examen debe estar correctamente presentado, con los nombres que se piden, el README.md completo con el nombre y apellido del alumno y el ejercicio con el nombre correspondiente. (10p)
7. El examen debe ser un fork de github del repositorio original donde se encuentra el examen. (10p)
